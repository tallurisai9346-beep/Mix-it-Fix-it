# Mix it Fix it

Mix it Fix it is my small experiment project I did on the web.

The main point of this project was to create something functional and simple to use without complicating the design.

## Project Goal

The goal of the project was to create a prototype with a simple interface so that the user can operate it without any problems.

I focused more on content rather than extra useless bloat on the page.

## What's The Point?

Simple interface

Easy navigation

Interactive buttons

Responsive design

Runs locally

Simple animations/effects

## Technologies Used

I used standard web tech stack:

HTML

CSS

JavaScript

## Why Did I Do That?

I wanted to expand my knowledge in Front-End development field.

By doing this project I tried to learn more about how HTML/CSS/JS works in real projects.

In process of building this project I encountered some challenges.

For example, the hardest part was to make the whole application work properly.

I also had issues with responsive design but eventually fixed them.

## What I Learned

I learned a lot of new stuff by doing this project. For example I improved my skills in:

Writing HTML

Styling pages with CSS

Interactivity with JavaScript

Fixing errors

Making responsive design

Deploying the app

## How To Use Locally

To launch this app on your local machine you need to:

1. Fork/Clone this repository.

2. Open cloned folder in your code editor.

3. Open index.html file in browser.

Also you can use VS Code with Live Server extension.
